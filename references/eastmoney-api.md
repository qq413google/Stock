# 行情 API 参考（东方财富 + 腾讯）

## 🔴 腾讯行情接口（`tasks/check-alerts.ps1` 盯盘专用，2026-08-14 补文档）

> **盯盘系统每分钟调用的就是它**，此前本文完全没有记录——改盯盘逻辑时无处查字段。

```
GET http://qt.gtimg.cn/q=sz300347,sh600519,sh000001      # 逗号分隔，可一次批量拉几十只
```
返回形如 `v_sz300347="1~泰格医药~300347~56.34~55.32~...";` ，用 `~` 分割后按**下标**取值：

| 下标 | 含义 | 备注 |
|---|---|---|
| `[1]` | 名称 | |
| `[2]` | 代码 | |
| `[3]` | **现价** | 直接是元，**不用 /100**（与东财不同） |
| `[4]` | **昨收** | 用于判断"今天是否新穿越"（armed 种子） |
| `[5]` | 今开 | |
| `[6]` | 成交量 | 手 |
| `[33]` | **当日最高** | 冲高回落止盈 `spikeFade` 用 |
| `[34]` | **当日最低** | "反弹收复"的 reclaim guard 用（2026-08-14 新增） |

**代码格式**：深市 `sz` + 6位（`sz300347`），沪市 `sh` + 6位（`sh600519`），指数 `sh000001`/`sz399001`/`sz399006`。

> ⚠️ 与东财的区别：①价格**不需要 /100** ②代码前缀是 `sz/sh` 而非 `0./1.` ③一次可批量拉多只，
> 盯盘正是靠这点把几十只票压缩成 1 次请求，实现每分钟轮询而不触发限流。
> ⚠️ `[33]/[34]` 只在返回字段足够长时存在，取值前必须判 `$f.Count -ge 34/35`。

## 🌎 美股接口（`scripts/overseas.js` 隔夜外盘 beta 用）

```
GET https://push2.eastmoney.com/api/qt/stock/get?secid={前缀}.{代码}&fields=f43,f58,f170
```
| 标的 | secid | 可用性 |
|---|---|---|
| 纳指100 / 标普500 / 道指 | `100.NDX` / `100.SPX` / `100.DJIA` | ✅ |
| 纳斯达克个股（英伟达等） | `105.NVDA`、`105.AMD`、`105.MU`… | ✅ |
| 纽交所个股（台积电） | `106.TSM` | ✅ |
| **费城半导体指数 SOX** | `100.SOX` | ❌ **本环境查无此 secid** |

> 因 SOX 拉不到，`overseas.js` 改用**9只半导体股等权平均**作费半代理（NVDA/AMD/MU/AVGO/INTC/AMAT/LRCX/ASML/TSM）。
> 价格 `f43/100`、涨跌幅 `f170/100`。

## 东方财富API参考

## 行情数据

### 实时报价
```
GET https://push2.eastmoney.com/api/qt/stock/get?secid={市场代码}.{股票代码}&fields=f43,f44,f45,f46,f47,f48,f57,f58,f60,f170,f168,f169
```

| 字段 | 含义 | 单位 |
|------|------|------|
| f43 | 现价 | 分(需/100) |
| f44 | 最高 | 分 |
| f45 | 最低 | 分 |
| f46 | 今开 | 分 |
| f47 | 成交量 | 手 |
| f48 | 成交额 | 元 |
| f57 | 代码 | — |
| f58 | 名称 | — |
| f60 | 昨收 | 分 |
| f170 | 涨跌幅 | **放大100倍(需/100得%)** ⚠️ 不是/10 |
| f168 | 外盘 | 手 |
| f169 | 内盘 | 手 |

> ⚠️ **f170 坑**：stock/get 默认未传 fltt 时，f170 是涨跌幅×100（如 -26 = -0.26%），**需 /100**。早期 index.js 误用 /10 导致涨跌幅放大 10 倍。
> ✅ 最佳实践（quote.js 采用）：不依赖 f170，直接用 `(f43-f60)/f60` 自算涨跌幅，价格字段统一 /100。

### 市场代码
- 深市: 0 (如 0.300433)
- 沪市: 1 (如 1.600584)

### 日K线
```
GET https://push2his.eastmoney.com/api/qt/stock/kline/get?secid={secid}&fields1=f1,f2,f3,f4,f5,f6&fields2=f51,f52,f53,f54,f55,f56,f57&klt=101&fqt=1&end=20500101&lmt={条数}
```
输出: 日期,开盘,收盘,最高,最低,成交量(手),成交额

### 分时走势
```
GET https://push2his.eastmoney.com/api/qt/stock/trends2/get?secid={secid}&fields1=f1,f2,f3,f4,f5,f6,f7,f8,f9,f10,f11,f12,f13&fields2=f51,f52,f53,f54,f55,f56,f57,f58&iscr=0&ndays=1
```
输出: 时间,开盘,收盘,最高,最低,成交量,成交额,均价

### 主力资金流向（当日实时）
```
GET https://push2.eastmoney.com/api/qt/stock/fflow/kline/get?secid={secid}&fields1=f1,f2,f3&fields2=f51,f52,f53,f54,f55,f56,f57,f58&lmt=1&klt=101
```
输出字段顺序（⚠️ 易错）: **f51日期, f52主力, f53小单, f54中单, f55大单, f56超大单** (单位:元)

> ⚠️ 顺序是 主力→**小→中→大→超大**，不是"超大→大→中→小"。早期 flow.js 把 f53(小单)当成超大单，导致多空判断反向。
> ✅ 校验恒等式：`主力 = 超大单 + 大单`（f52 = f56 + f55），不成立即数据/映射有误。
> ⚠️ 此接口只返回当日1条数据，不支持历史多日回查。

### 主力资金流向（历史多日）✅ 已可用
```
GET https://push2his.eastmoney.com/api/qt/stock/fflow/daykline/get?secid={secid}&fields1=f1,f2,f3&fields2=f51,f52,f53,f54,f55,f56,f57,f58&lmt={天数}&klt=101
```
输出字段：**f51日期, f52主力, f53小单, f54中单, f55大单, f56超大单, f57主力净占比%, f58小单净占比%**(净额单位:元，除1e8得亿)

> ✅ 字段顺序与当日接口一致(f52主力,f53小单,f54中单,f55大单,f56超大单)，恒等式同样成立。
> ✅ lmt参数控制返回天数（如lmt=10返回最近10日），最多约返回20条。
> ⚠️ **f57=主力净占比%(主力净额/成交额)、f58=小单净占比%，不是涨跌幅/换手率！** 经核验：06-26 主力-37.9亿 ÷ 成交227亿 = -16.68% = f57。主力净占比比主力绝对额更能判断"真出货"——它剔除了成交量大小，-16.68% 表示主力净卖出占当日成交的16.68%。
> flow.js已改用此接口实现多日查询：`node flow.js <secid> 5` 返回5日历史+连续净流出入统计+恒等式自动校验。

### 板块涨幅排名
```
GET https://push2.eastmoney.com/api/qt/clist/get?pn=1&pz={条数}&po=1&np=1&fltt=2&invt=2&fid=f3&fs=m:90+t:3&fields=f2,f3,f6,f12,f14,f20
```
字段: f2现价 f3涨幅% f6成交额 f12代码 f14名称 f20总市值。`fs=m:90+t:3`=概念板块。

> ⚠️ **f6=成交额，f20=总市值**，两者差一个量级。早期 sector.js 误用 f20 当成交额（把总市值上万亿印成"成交额"）。
